## Дүгнэлт

Ном нэмэх үйлдэлд давхардал, хоосон зохиолч, хязгаараас их он гэсэн гурван өөр зөрүү илэрсэн. Couch Potato аяллаар хоосон талбартай ном хадгалагдаж байгааг ажиглав. Fed-Ex аяллаар давтан нэмсэн ном хүснэгтэд хоёр мөр болсныг харсан. Saboteur аялал хамгийн үр дүнтэй байсан, учир нь тусдаа локал API шалгалтаар гурван зөрүүг дахин баталсан. 2199 онтой ном нэмэхэд хамгийн шинэ оны үзүүлэлт мөн өөрчлөгдсөн. Дэлгэцийн зургаас он таслалтай харагдаж, устгах товч ногоон байгааг бас анзаарав. Playwright-ээр номын мөр нэмэгдсэн эсэх, он хэрхэн харагдсан, буруу оролт хадгалагдсан эсэхийг шалгаж болно. Товчны өнгө ба харагдах байдлыг хүн шууд анзаарах бөгөөд өнгөний дүрэм тогтсон бол автомат шалгалтад нэмж болно. Дараагийн тестээр хайлтын том, жижиг үсэг болон устгасны дараах тоолуурыг шалгана.
